# AI usage

AI assistance (GitHub Copilot in VS Code) was used during development to help implement and refine backend API behavior, frontend behavior, Docker configuration, documentation, and automated tests. It was also used to review assignment requirements, investigate reported issues, and suggest validation steps.

The resulting code and test suggestions were checked against the repository and validated by running the backend integration tests, frontend lint and production build, and frontend API-client tests. AI-generated suggestions were not treated as a substitute for running the application or tests.
